## Apa Itu AI Benchmark

Benchmark adalah dataset dan tugas standar yang digunakan untuk mengukur dan membandingkan performa model AI. Berbagai benchmark mengukur aspek berbeda: reasoning, coding, math, language understanding, dan safety. /glossary/Benchmark dan /glossary/Evaluation.

## Benchmark Utama 2026

- **MMLU** — general knowledge baseline
- **HumanEval** — coding capability benchmark
- **CyberGym** — security evaluation benchmark (digunakan Microsoft MDASH)
- **CTI-REALM** — Microsoft benchmark untuk AI agents pada security
- **Custom domain benchmarks** — untuk industry-specific evaluation

## FAQ

- **Apa benchmark yang paling penting?** Tergantung use case. MMLU untuk general knowledge, HumanEval untuk coding, CyberGym untuk security evaluation.
