## Metadata Schema

Chunk: source_id, page_number, section_header, create_date, access_level.

## Filtering Strategy

Combine vector search dengan metadata filter. RRF (Reciprocal Rank Fusion) untuk reranking.

## Access Control

User only retrieve chunks dengan access_level <= user clearance.
