## Knowledge Graph Basics

Nodes (entities), edges (relations), properties. Representasi terstruktur untuk domain knowledge.

## Integration dengan LLM

LLM extract triplets dari text. Embed graph untuk similarity search.

## Query Pattern

SPARQL atau Gremlin untuk complex queries. Graph-native untuk multi-hop reasoning.
