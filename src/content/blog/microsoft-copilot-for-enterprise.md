## Microsoft 365 Copilot

Embedded di Word, Excel, PowerPoint, Teams. Natural language interface untuk office productivity.

## GitHub Copilot

Context-aware code completion. Copilot Chat untuk reasoning. Enterprise plans with organization-wide knowledge base.

## Custom Copilots

Microsoft Copilot Studio untuk low-code custom copilots. Connect ke data source, trigger actions, deploy di Teams.
