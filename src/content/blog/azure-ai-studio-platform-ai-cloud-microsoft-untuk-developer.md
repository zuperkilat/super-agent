## Apa Itu Azure AI Studio

Azure AI Studio dari Microsoft menyediakan lingkungan terintegrasi untuk membangun, train, dan deployment AI models. Mendukung model dari Microsoft (Copilot), Anthropic (Claude, Mythos), dan model komunitas lainnya (/glossary/Azure dan /glossary/Mythos).

## Ekosistem Microsoft untuk AI

Microsoft terus memperluas AI ecosystem melalui Azure OpenAI Service (GPT-4o, o1), Copilot integration across Microsoft 365, dan Mythos dari Anthropic untuk secure software development.

## FAQ

- **Apa itu Azure AI Studio?** Platform cloud Microsoft untuk membangun dan deploy AI solutions secara end-to-end. /glossary/Azure.
- **Apakah Mythos tersedia di Azure AI Studio?** Ya, Claude Mythos Preview dari Anthropic tersedia melalui Azure AI Studio integrasi. /glossary/Mythos.
