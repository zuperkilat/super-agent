## MaxSim Operation

Compute query-document similarity per token. Max Pooling across document tokens. Late interaction more accurate than early interaction.

## Indexing

Precompute document token embeddings. Store in FAISS or vector DB. At query time, compute query tokens on-the-fly.

## Implementation

ColBERT v2 dengan PLAID indexing. LoTTE benchmark untuk evaluation.
