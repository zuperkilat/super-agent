## Apa Itu Claude Code

Claude Code adalah AI coding tool dari Anthropic yang dirancang untuk developer AI. Berbeda dari Claude Chat, Claude Code fokus pada autonomous coding tasks: menulis code, debugging, refactoring, dan review code secara end-to-end /glossary/Claude Code.

## Cara Menggunakan Claude Code

Claude Code terintegrasi dengan terminal dan IDE. Developer bisa menggunakannya untuk: menulis code dari specification, debugging dan fixing errors, code review dan suggestions, dan autonomous multi-file work. /glossary/Agentic coding.
