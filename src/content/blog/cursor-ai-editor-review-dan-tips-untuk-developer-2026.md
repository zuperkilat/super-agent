## Apa Itu Cursor

Cursor adalah code editor (fork dari VS Code) dengan AI yang terintegrasi ke dalam intinya secara native. Berbeda dari Claude Code yang berbasis conversation, Cursor memberikan AI assistance secara inline dalam IDE menggunakan model yang berbeda.

## Best Practice untuk Cursor

1. Manfaatkan multi-file context untuk memahami codebase secara keseluruhan
2. Gunakan @codebase notation untuk menganalisis seluruh proyek
3. Configure custom rules dan .cursorrules untuk code style consistency
4. Integrasikan dengan MCP untuk external tool access
5. Manfaatkan multi-model support untuk beragam task types

- **Apa itu Cursor AI editor?** AI-powered code editor berbasis VS Code fork dengan integrated AI capabilities.
