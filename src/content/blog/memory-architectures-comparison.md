## Short-Term Memory

Conversation context window. Volatile, limit token size. Reset every session.

## Long-Term Memory

Persistent storage di database. Retrieved via embedding similarity. Unlimited size.

## Episodic Memory

Record agent experience chronologically. Replay untuk learning dan debugging.

## Semantic Memory

Knowledge graph atau vector store untuk factual knowledge. Structured, queryable.
