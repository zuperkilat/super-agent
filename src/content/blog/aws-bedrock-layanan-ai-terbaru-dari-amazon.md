## Apa Itu AWS Bedrock

Amazon Bedrock adalah layanan cloud dari AWS yang menyediakan akses ke model AI dari berbagai provider (Anthropic Claude, AI21 Labs Jurassic, Cohere Command, Stability AI, dan lainnya) melalui API yang seragam. Tidak perlu mengelola infrastructure sendiri untuk deployment model AI. /glossary/Bedrock.

## Kapan Harus Menggunakan Bedrock

Gunakan Bedrock ketika: ingin akses ke banyak model tanpa mengelola infrastructure, perlu integrasi dengan AWS ecosystem (Lambda, S3, DynamoDB), atau menginginkan deployment yang scalable dengan managed service.

## FAQ

- **Apa itu AWS Bedrock?** Layanan cloud AWS untuk mengakses model AI dari banyak provider melalui satu API tunggal.
- **Model apa saja yang tersedia?** Anthropic Claude, AI21 Labs Jurassic, Cohere Command, Stability AI, dan model tambahan lainnya yang terus bertambah.
