## Memulai dengan n8n

n8n 2.0 menawarkan visual workflow builder yang terintegrasi dengan LangChain. Langkah pertama: install n8n, hubungkan dengan API provider (OpenAI, Anthropic, atau Google), dan buat workflow pertama dengan template yang tersedia.

## Integrasi LangChain di n8n

n8n 2.0 mendukung LangChain chains secara native. Anda bisa membuat RAG pipelines, tool-calling agents, dan multi-step workflows menggunakan antarmuka visual n8n tanpa menulis kode LangChain manual.

## FAQ

- **Apa itu n8n?** Platform automation visual open-source untuk membangun AI workflows. /glossary/n8n.
- **Bagaimana cara memulai dengan n8n dan LangChain?** Install n8n via npm atau Docker, tambahkan LangChain integration dari n8n marketplace, dan deploy workflow.
