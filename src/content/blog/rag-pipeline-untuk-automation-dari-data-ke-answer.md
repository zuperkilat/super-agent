## Apa Itu RAG Pipeline

RAG pipeline terdiri dari: 1) Data Ingestion (mengumpulkan dan memproses documents), 2) Chunking (memecah dokumen menjadi chunks yang manageable), 3) Embedding (mengubah chunks menjadi vectors), 4) Vector Storage (menyimpan di vector database seperti Pinecone atau Qdrant), 5) Retrieval (mencari chunks relevan saat query), 6) Generation (LLM menggunakan retrieved context untuk menghasilkan answer). /glossary/RAG.

## Mengapa RAG Penting untuk Automation

RAG memungkinkan AI automation untuk mengakses informasi real-time dan spesifik domain tanpa perlu fine-tuning. Ini membuat sistem lebih fleksibel dan tidak memerlukan data training yang mahal.
