## Apa Itu Agentic Coding

Agentic coding menggunakan AI agent yang bisa menulis code, menjalankan tests, memperbaiki bugs, dan melakukan refactoring secara autonomous tanpa pengawasan terus-menerus. /glossary/Agentic coding adalah evolusi dari AI-assisted coding dimana AI bukan sekadar memberikan suggestions tetapi bertindak sebagai developer assistant yang bisa menyelesaikan tugas secara end-to-end.

## Siklus Agentic Coding

1. Developer menentukan goal dan specification
2. AI agent merencanakan implementation steps
3. Agent menulis code dan test cases
4. Agent menjalankan tests dan menganalisis failures
5. Agent memperbaiki bugs berdasarkan test results
6. Repeat sampai semua tests pass

agent loop adalah konsep fundamental yang memungkinkan proses ini berjalan secara autonomous. /glossary/Agent Loop.

## FAQ

- **Apa itu agentic coding?** AI agent yang menangani coding tasks secara autonomous dari writing sampai debugging.
- **Apa bedanya dengan AI-assisted coding?** Agentic coding bisa mengeksekusi dan memperbaiki code secara berulang tanpa user intervention langsung.
