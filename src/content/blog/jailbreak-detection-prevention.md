## Detection Patterns

Role override, DAN injection, base64 bypass, multi-turn manipulation. Regex + LLM classifier combo.

## Prevention Layer

Input classifier: if jailbreak probability > threshold, reject request. Return standard refusal message.

## Monitoring

Track jailbreak attempts per user/id. Spike detection -> ban temporary.
