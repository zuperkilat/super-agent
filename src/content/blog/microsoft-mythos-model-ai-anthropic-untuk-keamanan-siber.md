## Apa Itu Microsoft Mythos

Microsoft mengumumkan integrasi model Claude Mythos dari Anthropic ke dalam Security Development Lifecycle (SDL). Model ini dirancang untuk meningkatkan keamanan perangkat lunak melalui AI-powered vulnerability scanning yang kuat (CSO Online, 23 April 2026).

## MDASH: Hasil Benchmark CyberGym

Sistem MDASH dari Microsoft mencapai skor 88,45% pada benchmark CyberGym, melampaui sistem single-model dalam vulnerability scanning (GeekWire, 13 Mei 2026). Microsoft mengevaluasi Mythos Preview menggunakan CTI-REALM benchmark buatan Microsoft sendiri untuk mengevaluasi AI agents pada keamanan siber (Microsoft MSRC Blog, April 2026).

## Dampak pada Industri

Integrasi Mythos menandai pergeseran signifikan: AI bukan lagi pelengkap tetapi komponen inti dari software development yang aman. Microsoft dan Anthropic bekerja sama untuk meningkatkan standar keamanan software secara global.

## FAQ

- **Apakah Mythos open-source?** Mythos Preview adalah model Anthropic yang diintegrasikan ke Microsoft SDL.
- **Apa itu benchmark CyberGym?** Benchmark untuk mengevaluasi AI agents pada tugas-tugas keamanan siber.
- **Apa MDASH dari Microsoft?** Sistem vulnerability scanning multi-agent AI yang menggunakan Claude Mythos dari Anthropic.
