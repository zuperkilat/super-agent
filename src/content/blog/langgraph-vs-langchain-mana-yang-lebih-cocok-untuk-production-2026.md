## Apa Itu LangChain

LangChain adalah framework untuk membangun aplikasi berbasis LLM. Ia menyediakan abstraksi untuk prompt templates, chains, agents, dan memory. /glossary/LangChain adalah salah satu framework paling populer untuk AI application development.

## Apa Itu LangGraph

LangGraph adalah framework dari same team (LangChain) yang fokus pada stateful multi-step agent workflows dengan graph-based architecture. /glossary/LangGraph cocok untuk agentic systems yang kompleks dengan branching dan looping.

## Kapan Memilih Mana

Gunakan LangChain untuk: aplikasi LLM sederhana, chains, dan RAG. Gunakan LangGraph untuk: agentic workflows dengan branching, loops, dan state management yang kompleks. /glossary/Agentic AI.

## FAQ

- **Apa perbedaan LangChain dan LangGraph?** LangChain untuk chains sederhana, LangGraph untuk graph-based agentic workflows.
- **Mana yang lebih baik untuk production?** LangGraph untuk agentic systems yang membutuhkan state management, LangChain untuk simpler LLM apps.
- **Apakah bisa menggunakan keduanya bersamaan?** Ya, banyak production systems menggunakan keduanya secara bersamaan untuk kebutuhan yang berbeda.
