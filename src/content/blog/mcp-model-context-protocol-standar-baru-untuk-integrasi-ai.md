## Apa Itu MCP

Model Context Protocol (MCP) adalah standar terbuka yang memungkinkan koneksi aman dua-arah antara sumber data dan AI-powered tools. Bayangkan MCP sebagai USB-C untuk AI membuat integrasi model dengan tools lebih mudah (Anthropic, November 2024).

## MCP 2026-07-28: Update Terbaru

Spesifikasi MCP versi baru resmi versioned 2026-07-28, dengan release candidate tersedia. Update ini menambahkan kemampuan baru untuk production use dan mengatasi growing pains yang diidentifikasi di skala enterprise (aaif.io, 28 Juli 2026).

## Siapa yang Menggunakan MCP

MCP didukung oleh Anthropic (creator), Google (Cloud adoption via Cloud discovery), dan framework AI lainnya. MCP reference server tersedia di GitHub resmi Model Context Protocol.

## FAQ

- **Apa itu MCP?** Model Context Protocol — standar integrasi AI dan tools. Lihat /glossary/MCP untuk detail.
- **MCP vs API integrasi biasa?** MCP menyediakan standardisasi protocol yang membuat integrasi lebih mudah dan interoperabel antar provider.
- **Siapa yang menciptakan MCP?** Anthropic menciptakan MCP pada November 2024 sebagai open-source protocol.
- **Apa itu MCP 2026-07-28?** Versi baru spesifikasi MCP yang dirilis 28 Juli 2026 (hari ini!) dengan perbaikan untuk production use.
- **Apa itu release candidate?** Release candidate adalah versi hampir final dari software yang siap untuk testing oleh komunitas sebelum peluncuran resmi.
