## ONNX Optimization

ONNX Runtime optimize graph execution, quantization, dan operator fusion. Support CPU, GPU, dan NPU.

## Quantization INT8/INT4

Dynamic quantization tanpa calibration. Weight-only quantization untuk LLAMA, Mistral.

## Production Deployment

Bundle model ke ONNX, serve dengan ORT runtime. Memory footprint lebih kecil daripada PyTorch.
