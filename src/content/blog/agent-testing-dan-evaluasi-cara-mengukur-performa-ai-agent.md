## Mengapa Agent Testing Penting

Agent testing memastikan AI agent beroperasi dengan benar, aman, dan sesuai harapan. Tanpa testing yang memadai, agent bisa menghasilkan output yang tidak diinginkan atau berbahaya. /glossary/Evaluation adalah proses mengukur kualitas model dan agent AI.

## Benchmark Utama untuk Agent Testing

- **CyberGym** — benchmark untuk mengevaluasi AI agents pada tugas-tugas keamanan siber. Microsoft MDASH mencapai skor 88,45% pada benchmark ini.
- **MMLU** — general knowledge evaluation benchmark untuk measure reasoning dan knowledge capabilities.
- **HumanEval** — coding evaluation benchmark untuk menilai kemampuan code generation agent.
- **CTI-REALM** — benchmark buatan Microsoft untuk mengevaluasi AI agents pada keamanan siber (Microsoft MSRC Blog, April 2026).

## Best Practice Agent Testing

1. Tetapkan clear success criteria sebelum testing
2. Gunakan representative test cases
3. Test safety guardrails secara berkala
4. Monitor agent behavior dalam production
5. Dokumentasikan semua test results untuk traceability
