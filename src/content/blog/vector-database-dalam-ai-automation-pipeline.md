## Apa Itu Vector Database

Vector database menyimpan data sebagai vector embeddings dan memungkinkan similarity search yang efisien. Dalam pipeline AI automation, vector database digunakan untuk RAG, memory, dan semantic retrieval. /glossary/Vector Database dan /glossary/Embedding.

## Vector Database Populer 2026

Pinecone (managed cloud), Qdrant (open-source), Milvus (distributed), ChromaDB (lightweight), dan pgvector (PostgreSQL extension) adalah pilihan populer untuk vector storage.

## FAQ

- **Apa itu vector database?** Database yang menyimpan dan mencari embeddings vector untuk similarity search, bukan keyword matching.
